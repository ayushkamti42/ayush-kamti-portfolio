# Ayush Kamti — Student Developer Portfolio

A responsive React + Vite portfolio starter.

## Run it on your computer

1. Install Node.js (LTS) if it is not already installed.
2. Extract this ZIP and open the folder in VS Code.
3. Open the VS Code terminal and run:

```bash
npm install
npm run dev
```

4. Open the local address printed in the terminal.

## Personalise it before publishing

- Replace the sample project cards in `src/main.jsx` with projects you have actually built.
- Change `your.email@example.com` to your professional email.
- Check your LinkedIn URL and update the LinkedIn link.
- Remove any skill you are not comfortable claiming yet.
- Update the About section as your experience grows.

## Publish it with Vercel

1. Push this project to a GitHub repository.
2. Sign in to Vercel using GitHub.
3. Choose **Add New → Project**, then import the repository.
4. Keep the default Vite settings and click **Deploy**.
5. Copy the live `https://...vercel.app` address into the Portfolio Link field.

Do not publish placeholder projects or contact details. Replace them first.
